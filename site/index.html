ONE LOCAL OPERATIONS CONTEXT

从“能登录”变成“知道该怎么维护”

服务器、端口、运行方式、公开入口和变更边界分属不同地方时，下一次部署往往只能重新猜。AI VPS Gateway 把这些信息连成可查询、可审计的本机运维上下文。

VPS INVENTORY AND SIGNALS

一台 VPS 可以没有网站，但不能没有状态

手动登记资产，先完成 SSH 绑定，再让网关按 TCP、SSH Banner 和 HTTP(S) 检查状态。性能快照和趋势留在本机，不需要给每台服务器安装常驻 Agent。

  • 不把 ICMP Ping 当成唯一在线判据
  • 直连模式可绕过本机 TUN 的 SSH 误告警
  • CPU、内存、磁盘与负载的历史趋势

PROJECT CONTEXT THAT SURVIVES SESSIONS

每次部署，留下下一位维护者能用的答案

项目档案保存技术栈、服务管理器、端口映射、Web 入口和五段式 Runbook。后续的 AI 会话先读上下文，再申请会话和执行操作。

  • Docker、systemd、PM2 和直接进程统一归档
  • Nginx 反代属于项目入口，不被误判为独立项目
  • 部署、验证、排错和变更边界可长期复用

A SMALLER, CLEARER OPERATIONS LOOP

从首次绑定到一次可复盘的 AI 运维

  1. 01

    添加并绑定

    新 VPS 自动生成专用公钥。你只需通过云控制台或已有入口完成一次安装，再点击测试绑定。

  2. 02

    盘点并沉淀

    只读盘点 Docker、systemd、PM2、端口和 Nginx 路由，生成可编辑的项目档案与 Runbook。

  3. 03

    AI 申请独占会话

    同一台 VPS 同时仅一个执行会话，其余请求排队。AI 不会得到私钥或本机任意 SSH 路径。

  4. 04

    执行后可追溯

    命令、结果和高危提示经过脱敏后进入审计记录，运维摘要与 Runbook 留作后续上下文。

SECURITY MODEL, WITHOUT THE MARKETING CLAIMS

本机控制边界，而不是一层“绝对安全”的包装

私钥不交给 AI

凭据由本机网关持有，MCP 客户端只能请求受控操作。

受租约的 SSH 执行

每台 VPS 有独占会话、排队、空闲超时和最长时限。

高危操作可见

常见不可逆命令被阻断，高危行为留下审计警告。

边界说清楚

它不是 OS 沙箱。同一 macOS 用户下的不受信任进程仍应被隔离。

MAKE THE NEXT ACTION OBVIOUS

先读状态，再让 Agent 动手

网关为后续会话提供当前性能、健康检查、项目关联与已执行操作。AI 的执行入口仍是 MCP，而不是把私钥复制进每一个会话。
